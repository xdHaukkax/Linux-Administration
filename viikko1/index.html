My Week 1 Cloud Computing Project

CSC Pouta | Ubuntu | Nginx | Cloud Infrastructure

About the Project

This project demonstrates the deployment of a public website using CSC Pouta cloud infrastructure. The website is hosted on an Ubuntu virtual machine.

1. What is CSC Pouta?

CSC Pouta is a cloud service that provides virtual machines and computing resources. It allows users to deploy and manage applications in the cloud.

2. What is a Web Server?

A web server receives HTTP requests from browsers and delivers web pages to visitors. This project uses Nginx as its web server.

3. How Can the Website Be Accessed?

The website is publicly accessible over HTTP through the virtual machine's public IP address. No login is required to view the page.
